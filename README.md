# Projek_KDJK_kel4_P2
Aplikasi PaaS Coolify


Coolify adalah sebuah PaaS (Platform as a service) aplikasi web open source berbasis self-hosted yang menjadi alternatif independen bagi developer untuk mengelola aplikasi, basis data, dan reverse proxy tanpa ketergantungan pada vendor cloud komersial seperti Heroku, Vercel, atau Netlify
